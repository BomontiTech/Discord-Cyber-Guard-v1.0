## 🛠️ Kurulum ve Çalıştırma / Installation & Usage

### 1. Kütüphaneleri Yükleyin / Install Dependencies
Klasörünüzde terminal açıp gerekli siber paketleri yükleyin:
```bash
pip install -r requirements.txt
```

### 2. Yapılandırma ve ID Girişi / Configuration
`main.py` dosyasını açarak `GELISMIS_LOG_KANAL_ID`, `SUNUCU_SAHIBI_ID` ve en alttaki `TOKEN` alanlarını kendi sunucu bilgilerinize göre doldurun.

### 3. Savunmayı Başlatın / Run
Hazırladığımız konsol kalkanı tetikleyicisiyle botu saniyeler içinde yayına alın:
```bash
py main.py
```
